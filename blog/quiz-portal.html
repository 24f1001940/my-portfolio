How I Built a Multi-User Quiz Portal

July 2025 · Full-stack development

The Quiz Master portal was built to make assessments easier to create, deliver, and review for multiple users at the same time.

Architecture

The application uses Flask for the API layer, Vue for the interactive client, SQLite for local development, and Redis with Celery for background work.

Real-time scoring

Answers are validated on the server so that scoring remains consistent. A background task handles result aggregation and keeps longer operations away from the request path.

What I learned

The project reinforced the value of small API boundaries, clear ownership of state, and testing the complete flow from quiz creation to the final result.
